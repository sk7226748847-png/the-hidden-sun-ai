# ☀️ The Hidden Sun AI

Welcome to **The Hidden Sun AI**!

## About
This is an AI Assistant designed to help students from **5th to 12th grade** with their academic queries, as well as answer general/external questions.

## Features
- Complete solutions for 5th to 12th class subjects.
- Answers to all general and external queries.
- Powered by OpenAI and Streamlit.
